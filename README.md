# Progression Services — website starter

A bilingual (Greek/English), responsive static website for GitHub Pages.

## Before publishing
1. Replace `ADD-COMPANY-EMAIL@example.com` in `index.html` with the company's public email address (both occurrences).
2. Replace the telephone placeholder in `index.html` with the public phone number, and make it a `tel:` link if desired.
3. Review every service description and confirm it accurately reflects the services the company provides.
4. Confirm you have permission to publish the property photographs and that no private or identifying details should be removed.

## Preview locally
Open `index.html` in a browser. The Google Fonts connection requires internet access; system fonts will be used if unavailable.

## Publish with GitHub Pages
1. Create a public GitHub repository named `progression-services`.
2. Upload all files and folders from this package (keep `index.html` in the repository root).
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then save.
6. Wait for the published URL to appear in the Pages section.

## Notes
- The site is static and does not collect or store form submissions.
- The email link opens the visitor's email application. Replace the placeholder address before publishing.
- A custom domain can be connected later.
- Review the site's privacy/cookie requirements before adding analytics, tracking, or third-party embedded services.
